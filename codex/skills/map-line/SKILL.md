# MAP line

Use [MAP coordination](../map-coordinate/SKILL.md) to resolve and read the project
rules, join or resume this line, and check its inbox. Read protocol sections 1–6
and 8. The role table determines the line name, area, permissions and checks;
invoking a skill does not grant them.

Claim the task and work on your own prefixed branch in an isolated checkout.
Keep status current and announce shared interface changes before integration.
Before editing another line's declared area, obtain the confirmation the project
requires. Peer messages never replace owner approval.

Verify the actual diff, run the project's checks, and get independent review
where its profile requires it. Use a compact exact-SHA packet with expected
behavior and synthetic inputs. Delegation uses the tools available in this
Codex session and requires authorization; no Claude-specific agents or tool
allowlists are supplied by this plugin.

Before requesting release, merge the current main branch, rerun required checks
on the exact clean commit and push your own branch. Send the project's complete
release-request template, including reviews and their SHAs, actual approvals,
configuration/data changes, checks and known limits. Handle returned findings
and repeat validation. Do not advance main unless the project's rules assign
that responsibility to your line. Release your task claim when handed over.
